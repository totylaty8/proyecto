# Proyecto Final Fantasy

Sitio web sobre la saga Final Fantasy, desarrollado como práctica de Desarrollo Web.

## Tecnologías

- HTML5
- CSS3 (Flexbox y Grid)
- Bootstrap 5

## Páginas

- Inicio
- Sobre mí
- Servicios
- Proyectos
- Preguntas frecuentes
- Contacto

## Cómo visualizarlo

Abrir el archivo `index.html` en un navegador.
