# Proyecto Final Fantasy

Sitio web sobre la saga Final Fantasy, desarrollado como práctica del curso de Desarrollo Web.

## Tecnologías utilizadas

- HTML5
- CSS3 (Flexbox y Grid)
- Bootstrap 5.3.3
- Google Fonts

## Páginas del sitio

- Inicio
- Sobre mí
- Servicios
- Proyectos
- Preguntas frecuentes (FAQ)
- Contacto

## Diseño responsive

El sitio utiliza Bootstrap y reglas CSS con media queries para adaptar la navegación, las imágenes, las tarjetas y la distribución del contenido a distintos tamaños de pantalla.

## Visualización local

Descargar o clonar el repositorio y abrir `index.html` en un navegador. Se requiere conexión a Internet para cargar Bootstrap y Google Fonts desde sus CDN.

## Publicación con GitHub Pages

Configurar GitHub Pages desde **Settings → Pages**, seleccionando la rama `main` y la carpeta `/ (root)`.

Una vez publicada, la dirección del sitio será:

https://totylaty8.github.io/proyecto/

## Control de versiones

El proyecto utiliza Git para registrar los cambios. La rama principal es `main` y las mejoras de esta entrega se trabajaron en `feature/mejoras-responsive`, que luego se integró en `main`.

Para consultar el historial de cambios desde la terminal:

```bash
git log --oneline --graph --all
```

## Publicación

La URL prevista para GitHub Pages es https://totylaty8.github.io/proyecto/. La publicación debe habilitarse en GitHub desde **Settings → Pages**, seleccionando la rama `main` y la carpeta `/ (root)`.
